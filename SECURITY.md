# Security policy

## Reporting a vulnerability

Please report suspected security issues privately through GitHub Security Advisories for this repository, rather than posting exploit details in a public issue. Include the affected version, impact, and steps to reproduce. We will acknowledge reports and coordinate a fix before public disclosure where possible.

Do not include bot tokens, API keys, private user data, or server invite links in reports.

## Supported version

Security fixes are currently considered for the latest published version.
