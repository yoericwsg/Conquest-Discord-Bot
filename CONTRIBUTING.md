# Contributing

1. Open an issue for larger changes so the scope can be discussed first.
2. Keep changes focused and do not include tokens, `.env` files, production data, or private server information.
3. Run `npm test` and describe the result in your pull request.
4. Explain any changes that affect permissions, moderation, AI data flow, or stored user data.

By submitting a contribution, you agree that it may be distributed under the repository's MIT license.
